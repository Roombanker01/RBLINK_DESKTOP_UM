# What changed in this version

This manual revision covers the user-visible changes in **RBLINK DESKTOP v0.1.3**.

- Company logos larger than 200 KB are refused. A failed replacement keeps the existing logo, and a company without a usable logo shows the default avatar.
- Hub protection now distinguishes the mutually exclusive Disarm, Arm Stay, and Arm Away modes from independently selectable custom defence zones. Up to eight named custom zones can be enabled.
- The Hub list orders its standard protection controls as Arm Stay, Arm Away, then Disarm. Hub logs cannot be requested when ten logs already exist; delete an old log first.
- IPC Camera devices use the camera icon. A device with no reported battery value shows `-`.
- Language selection applies immediately and remains selected when it cannot be synchronized. The product offers Chinese and English; Turkish is provided for this manual only.
- Notification badges use 1-9, 9+, 99+, and 999+ ranges. Mark All Read refreshes both the list and unread count when it finishes.
- The product name is RBLINK DESKTOP and unnecessary platform subtitles are no longer shown on sign-in or application screens.
