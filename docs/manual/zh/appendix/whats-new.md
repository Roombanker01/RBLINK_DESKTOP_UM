# 本版本更新

本次说明书修订覆盖 **RBLINK DESKTOP v0.1.3** 的用户可见更新。

- 公司 Logo 超过 200 KB 会被拒绝；替换图片选择失败时保留原 Logo；没有可用 Logo 时显示默认头像。
- Hub 防护区分互斥的 Disarm、Arm Stay、Arm Away 与可独立启用的自定义防区；最多可启用 8 个按后台名称显示的自定义防区。
- Hub 列表的标准防护按钮顺序为 Arm Stay、Arm Away、Disarm。已有 10 条日志时不能获取新日志，须先删除旧日志。
- IPC Camera 使用摄像头图标；未报告电量的设备显示 `-`。
- 选择语言后立即生效，无法同步时仍保留已选语言。应用界面仅提供中文和英文；土耳其语仅用于本说明书。
- 通知角标按 1-9、9+、99+、999+ 显示；全部标为已读完成后，列表和未读数会同时刷新。
- 产品名称为 RBLINK DESKTOP；登录和已登录界面不再显示多余的平台副标题。
